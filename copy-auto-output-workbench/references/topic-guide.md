# 选题口径指南（统一选题池：四栏 × 4 = 16 个）

> **唯一口径来源。** 本文件同时服务 `copy-auto-output-workbench` 与 `短视频工作台` —— 两者共用同一份选题池，**不再分别出「文案选题」和「短视频选题」**。出题前必读，避免方向跑偏。

## 总原则

- 每栏 4 个，共 16 个。
- **每个选题必须给三点：① 选题是什么 ② 为什么选 ③ 渠道落点（重点，2026-10-10 新增）**

### ① 选题是什么
一句事实。**必须标注准确的发布时间/时效状态**，让用户一眼分清新旧。可选时效标签：
- `【今日新发布】`：当天发布，最热乎
- `【近 3 天】`：近 1-3 天发布/更新
- `【早前发布 · 近期热议】`：早已上线，最近又被展示/讨论（如「8 月上线的 Wan3.0，云栖大会重点展示」）
- 必须核实准确时间，绝不把旧消息写成新消息（教训：Wan3.0 是 8 月上线，曾被误写成"今天云栖发布"）。

### ② 为什么选
时效性 + 受众痛点 + 爆款角度。

### ③ 渠道落点（**取代旧的"口播钩子"单点判断**，2026-10-10 用户拍板）

**旧口径的问题**：老规则要求"每个选题都必须同时撑得起公众号 3000 字深度文 + 短视频 60~90 秒口播，写不出钩子就淘汰"。但用户的主战场是公众号——**有些选题本来就是给公众号写的**（个人情感、行业自省类），硬把"能不能拍短视频"当准入门槛，等于把好选题提前毙掉；而**真实的坑是相反的**：写完之后才发现这篇转不了推荐流，等于白等一天。

**新口径**：不再用"必须三端通吃"做准入门槛，改成**立项时就把每个渠道的落点写清楚**，让用户当天就知道这题能吃到哪几条鱼。判定从"事后"提到"立项"。

每个选题必须逐渠道标出落点：

| 渠道 | 要写什么 | 标记 |
|---|---|---|
| **公众号** | 主稿角度（一句话说这题从哪个角度写成 3000 字） | 一律 ✅（它是主战场，不需要判断） |
| **抖音 / 视频号** | 3 秒钩子（一句开场） | `✅ 可转` / `🔄 换角度`（写明换成什么角度）/ `❌ 不可转` |
| **小红书** | 搜索词（用户会搜什么词进来看） | `✅ 有搜索词` / `🔄 换写法可搜`（写出换成哪个词）/ `❌ 无搜索词` |
| **播客** | 默认全可转，**不占字段**；除非这题明显不适合口播，才标一句 | —— |

并在末尾给一个**结论标记**：
- `🌟 三端通吃`：公众号 + 推荐流 + 小红书都能吃 → 优先做
- `📱 推荐流强`：短视频/小红书是主力，公众号可写可不写
- `📖 仅公众号`：只适合公众号（粉丝经营），**不要指望它带推荐流量**

**每栏的配比要求**：每栏 4 个里**至少有 2 个标 `🌟 三端通吃`**，其余可以是 `🔄 换角度` 或 `📖 仅公众号`，但**不允许整栏 4 个全是 `📖 仅公众号`**——那样等于这栏对短视频/小红书没有产出。

**判定要讲理由**：标 `❌ 不可转` 或 `❌ 无搜索词` 时，必须一句话说清为什么（例：「无身份代入，钩子写不出来」「没有搜索词，小红书搜不到」），否则用户没法判断我们是不是偷懒。

### 排版格式（固定，照抄）

```
【3-2】AI 直播切片一键批量出                【近 3 天】

① 是什么：某工具 10/8 上线批量切片功能，一次可出 30 条
② 为什么选：跨境卖家每天要切 30+ 条，痛点极硬；同类工具都在憋这个功能

③ 渠道落点：
   公众号       ✅  主稿角度＝"一个人一天切 30 条直播切片，我是怎么做的"
   抖音/视频号   ✅  3 秒钩子＝"一个人，一天，切了 30 条直播切片"
   小红书       🔄  换写法可搜 → 搜索词「直播切片怎么做」「剪辑提效」
   播客         ✅  （默认）

   → 结论：🌟 三端通吃
```

「仅公众号」的长这样：

```
【1-4】我回村待了三天，发现这里跟 AI 没关系       【早前发布 · 近期热议】

① 是什么：……
② 为什么选：……

③ 渠道落点：
   公众号       ✅  主稿角度＝"割裂感：一边是 AI 一边是乡土"
   抖音/视频号   ❌  无身份代入，钩子写不出来
   小红书       ❌  没有搜索词，搜不到

   → 结论：📖 仅公众号（写给老粉，不指望带推荐流量）
```

### 其余规则

- **四类内容在栏内混合**，不单一堆砌某一类：
  - **a 爆款案例**：必须真实可信，优先官方数据 / 上市公司财报 / 平台政策 / 公认行业现象；**绝不用**营销软文、论坛传闻的"单品爆款数字"。
  - **b 行业事件**：值得写、行业相关性够的。
  - **c 工具/模型更新**：必须讲清"对做电商的实际影响"，不做资讯搬运。
  - **d 博主行业观点**：尹晨自己的判断。
- 栏内按「时效 + 痛点 + 爆款潜力」排序，每栏末尾标 1 个重点推荐（优先推 `🌟 三端通吃` 的）。
- 用户按「栏目 + 编号」选定 1 个（如"素材生产的第 2 个"）。**选定后按该题的「渠道落点」执行**：标 ✅ 的渠道直接产出，标 🔄 的按写明的换角度方案产出，标 ❌ 的渠道不发。
- **锚点 = 电商从业者真问题 + 博主判断**。不追无关 AI 圈时事、不挑行业相关性小的鸡肋题、不用假案例。

## ① AI+电商素材生产（4 个）

- **口径**：AI 怎么帮卖家生产素材（主图 / 带货短视频 / 详情页 / 直播贴片 / 产品图本地化）。
- **出发点**：允许直接以 AI 产品/工具为出发点（可蹭当天 AI 发布热点）。
- **选题方向清单**：
  1. 图像生成（主图 / 详情页 / 改款变体）
  2. 视频生成（带货短视频 / 口播 / 混剪）
  3. 直播素材与跨境本地化（贴片 / 话术卡 / 切片 / 多语言多市场改图）
  4. 爆款结构复刻与批量派生（去重 / 变体 / 单图派生多场景）

## ② AI+岗位提效与降本（4 个）

- **口径**：AI 怎么帮电商各岗位提速降本（运营 / 客服 / 投流 / 美工 / 文案 / 选品），以及团队成本结构的变化。
- **出发点**：允许直接以 AI 产品/工具为出发点。
- **选题方向清单**：
  1. 客服（售前售后 / 跨境夜班）
  2. 投流（素材衰退预警 / 数据优化）
  3. 选品测品 + 运营日常（周报 / 复盘 / 上架 / 数据分析）
  4. 降本账本（算力与工具成本 / 外包与人力结构 / 夜间批量托管这类"无人值守"玩法）

## ③ AI+电商趋势与观点（4 个）—— 口径最关键，勿偏

- **口径**：**以电商行业为主体、AI 为变量**，讲「AI 正在怎样改变电商行业」的变化趋势；观点/判断为主，非资讯搬运。
- **红线**：**不要**拿某个 AI 产品 / 技术更新硬套电商（如"某模型发布 + 和电商结合"）。①②④ 才允许直接以 AI 产品为出发点。
- **选题方向清单（4 个固定方向）**：
  1. 素材生产力（谁在生产素材、成本结构变化）
  2. 岗位结构（执行岗被重构、团队"人少还是人贵"）
  3. 竞争格局（内卷加剧、成本下探、利润重塑、谁在裸泳）
  4. 平台生态与行业风向（平台对 AI 素材/AI 工具的态度、达人生态、算法新变量、话语体系与培训服务商动向）
- **示例（用户认可）**：
  - ✅「AI+电商成了 26 年培训主旋律：旧酒换新瓶，还是真有东西？」
  - ✅「AI 把门槛打低之后，电商内卷反而更狠了」
  - ❌「Airbnb/Pinterest 用 Qwen」——这是 AI 产品出海新闻，属④或①，不属于③

## ④ AI+商业与企业落地（4 个）

- **口径**：面向企业的 AI 赋能（AI 内训 / FDE / 落地部署），服务 B 端受众。
- **出发点**：企业视角。
- **选题方向清单**：
  1. AI 公司商业化（IPO / 营收 / 融资 / 算账）
  2. 企业落地方法论（业务流先行、技术不是第一位）
  3. 组织变革与人心（员工怕什么、怎么化解恐惧）
  4. FDE / AI 内训这门生意 + 复合人才（懂业务+懂模型+能交付）
