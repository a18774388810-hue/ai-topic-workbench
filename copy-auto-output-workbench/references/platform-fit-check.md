# 平台适配判定（写转化文案之前必须先做）

> 2026-10-10 用户明确要求的流程改动。
> 原流程：公众号定稿 → 直接缩写 → 小红书 + 短视频口播。
> **问题**：有些文章的**选题本身**就不适合推荐流平台，缩写只是把不适合的内容换个长度再发一遍。**选题错了，怎么拍都没用。**
> 新流程：公众号定稿先进本表 → 出判定 → 只有判定为 ②/③ 才产出文案。

## 一、根子上的差别（所有判据都从这一条来）

| | 公众号 | 抖音 / 视频号 / 小红书 |
|---|---|---|
| 分发 | **订阅制** | **推荐制** |
| 观众是谁 | 冲"你这个人"来的老粉 | 算法从陌生人里捞的 |
| 所以什么能活 | **我的感受、我的经历**有市场 | 算法只做一件事：**给内容打标签 → 找对这个标签感兴趣的人 → 看完播/互动/收藏决定推多少** |

**推论：推荐流的生死线是「你的内容能不能被打上标签」。打不上标签 = 进不了流量池 = 内容再好也出不去。**

「我欠 DeepSeek 一个道歉」在推荐流活不了，不是因为写得不好，是因为**算法标签库里没有"某人的道歉"这个类目**。

## 二、三关尺子（每次逐条过）

1. **能不能被标签化？** 算法能不能一眼看出该推给谁。
2. **标签池里有没有钩子？** 那个池子的人刷到你，凭什么停下来。
3. **看完他拿到了什么？** 技巧 / 判断 / 信息 / 情绪 —— 必须至少有一个是"他的"，不是"你的"。

- 三关全过 → **② 可直接缩写**
- 标签对得上，钩子/收获不对 → **③ 换角度**
- 标签都对不上 → **① 明确不发**

## 三、三个平台各不相同（别当一回事）

### 抖音 —— 要"这事跟我有关"
- 机制：兴趣推荐 + **完播为王**。冷启动只给几百人，**前 3 秒**决定生死。
- 用户状态：被动刷、无目的、注意力 3 秒。
- 吃：痛点、反差、反常识、身份代入、强情绪、强观点。
- 不吃：铺垫、思辨、无结论的叙述、**别人的私人情感**、宏观叙事。
- 例外：**认知/思维类**能活（"怎么判断一件事"这类干货），但主角必须是"方法"，不是"我"。

### 视频号 —— 要"值得我转给朋友"
- 机制：社交推荐（朋友点赞）+ 机器推荐混合，**社交权重高**。所以"值得转发"比"看完即走"值钱。
- 用户状态：偏 30+，看"涨见识"的内容，**对深度和观点的容忍度明显高于抖音**。
- 吃：观点、认知、值得转发的判断、信息增量。
- 不吃：纯情绪、无观点的记录。
- 结论：**信息密度高但不够"爽"的稿子，视频号是三家里唯一可能接住的。**

### 小红书 —— 要"这个我能存下来用"
- 机制：**搜索 + 收藏**。唯一一个"用户带着问题主动来"的平台。**有没有搜索词，是生死线。**
- 用户状态：主动找答案，会收藏、会抄作业。
- 吃：干货教程、清单、避坑、对比、可复制的方法。
- 不吃：**无搜索词的观点输出**、纯个人抒情、行业宏观叙事（"中国 AI 崛起"在小红书基本没人搜）。
- 情绪类只有"共鸣型"能活，且必须具体到"我也是这样"。

## 四、固定输出格式（先判定，再动笔）

```
【判定】① 不适合 / ② 可直接缩写 / ③ 建议换角度
【逐平台】
  抖音：标签 / 钩子 / 收获，逐条说清过不过关
  视频号：同上
  小红书：同上
【如果 ②】→ 直接出小红书文案 + 短视频口播
【如果 ③】→ 给 2-3 个可独立成篇的新选题，每个标注：
            新主题 / 目标人群 / 3 秒钩子 / 建议平台 → 用户选一个再写
【如果 ①】→ 说明为什么，并给出"如果要发，必须先改什么"
```

## 五、"换角度"怎么做（③ 的执行方法）

**换角度不是另写一篇，是从同一篇里抽出那个能被打上标签的骨头。**

三步：
1. 找出这篇里**可迁移的知识/判断**（不是"我的感受"，是"这件事的规律"）
2. 给它配一个**平台的搜索词或兴趣标签**
3. 用一个**钩子**把它包起来（钩子和主题一起换，不能只换主题）

**关键原则：把"我"从主角换成"讲的人"。** 用户不关心你怎么想，只关心他能拿到什么。

## 六、更上游的一条（建议）

**不要等文章写完再想转化。** 写公众号的时候就顺手埋 1-2 个"可独立成篇的骨头"：
一篇 4000 字的稿子里本来就有三四个论据段，写完时标出**信息密度最高、且不需要读者认识你**的那 1-2 段 —— 那一段就是短视频/小红书的选题。
这样用户交稿时就能直接得到"这篇的骨头在哪"，不用事后硬拗。

## 七、已经踩过的案例（不要重犯）

| 文章 | 判定 | 原因 |
|---|---|---|
| 回农村·城市满眼 AI 农村跟 AI 没关系 | **① 不发**（或③换成"AI 红利到底覆盖了多少中国人"） | 纯个人情感，抖音/小红书都给不出标签，没有搜索词 |
| 我欠 DeepSeek 一个道歉 | **③ 换角度** | 自省内容只对老粉有效；抖音不吃"我错了"，小红书没搜索词。骨头应换成"美国封了七年中国 AI 怎么活下来的"（视频号）、"开源 vs 闭源差在哪"（小红书） |

> 共同点：**不是内容不好，是放错了地方。** 个人情感留在公众号 —— 那 8 万粉丝本来就是为了"你这个人"来的。

## 八、长口播的写法：中段之后不能"只剩总结"（2026-10-10 用户反馈）

**现象**：一篇讲"美国围堵七年 → DeepSeek 破局"的口播稿，写到"门槛被换掉了"之后就开始赶，后面全是总结陈词，观众感觉**突然结束**。

**病根（通用规律）**：**新事实断了，只能用口号收尾。** 只要后半段没有新的信息增量，写的人就只剩两个动作——重复前面的结论，或者抒情。**抒情就是"矫情"的来源。**

**解法：在收尾之前补"事实段"，而不是补"观点段"。** 同一主题可以从四个方向挖新事实：

| 补什么 | 例（DeepSeek 篇） |
|---|---|
| **处境段** —— 对手强到什么程度，自己难受在哪 | 那几年中国这边：卡买不到 / 有卡也不知道怎么用 / 好模型都在别人手里 |
| **高光时刻段** —— 关键那一夜/那一天发生了什么具体的事 | 2025-01-27 英伟达一天蒸发 5890 亿，连美国电力股都被带崩 |
| **人物段** —— 做事的人是谁，有什么反差的细节 | 梁文锋：8 万本金 → 1 万张卡 → 事发当天在老家球场踢球 |
| **远方段** —— 今天走到了哪，有哪些可印证的事实 | 梯队成型 / 模型出海分成 / 16 万颗国产芯片 |

**收尾怎么写才不矫情**：不要用"精神口号"收（"堵住了卡没堵住人"——用户判为矫情），要用**对比 + 落点**收：
- 对比：七年前问"中国什么时候能追上来" → 今天问"下一家会是谁"
- 落点：**落到观众自己身上**（"不在榜单上，在你每个月那张账单上"）

**长度控制**：视频号深度口播可到 5~8 分钟（≈2000~3000 汉字 @350~380 字/分）。写完后必须**实测字数**并在文头标注"删哪一段可压到几分钟"，让用户自己裁剪；**不要凭空估字数**（AI 估字数普遍偏低 30% 以上，必须用脚本数汉字）。
